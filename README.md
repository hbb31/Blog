# Blog

A personal blog for long-form writing on technology, productivity and lifestyle, with its own git-based CMS.

- **Site:** Astro 7 (static output), MDX content collections, serif reading typography, light/dark themes
- **CMS:** Keystatic at `/keystatic`: posts, pages, categories, media, author profile, site settings
- **Workflow:** edit in the CMS → branch preview on Netlify → merge to `main` → live
- **Search:** Pagefind (built at deploy time, runs in the browser)
- **No trackers, no third-party scripts.** The newsletter (Buttondown) and share buttons are plain HTML.

## Quick start

```bash
npm install
npm run dev
```

Site: http://127.0.0.1:4321 · CMS: http://127.0.0.1:4321/keystatic

```bash
npm run build && npm run preview   # production build incl. search, at http://localhost:4321
npm test                            # Playwright + axe (after a build)
```

## Replace the placeholders

Search the repo for `PLACEHOLDER`. Most of it is editable in the CMS:

- **Site settings:** title, tagline, site URL, newsletter username (Buttondown), footer, social links, default share image
- **Author:** name, photo, bios, links
- **Posts and pages:** the four sample posts, the draft, About, Contact and Colophon
- Images in `src/assets/images/` were generated by `scripts/make-placeholder-images.mjs`.
